# Правила роботи

Основні правила проєкту наведено в `AGENT.md`; дотримуйся їх під час роботи.

- Нові категорії та правила віднесення операцій до них додавай лише через `rules.csv`. Фіксованість витрат також визначай у `rules.csv`.
- Якщо рахунок нової категорії ще не відкритий, додай директиву `open` у `main.beancount` до першої операції.
- Не редагуй `transactions.beancount` вручну: після зміни правил перегенеруй його командою `uv run python import.py`, перевір облік через `uv run bean-check main.beancount` і онови звіт через `uv run python report.py --through YYYY-MM-DD` із фактичною датою покриття виписки.
